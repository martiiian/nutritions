# Nutritions

Deno CLI для подсчёта дневного потребления КБЖУ на основе Obsidian
markdown-файлов.

## Установка

Требуется [Deno](https://deno.land/) v2+.

```bash
git clone https://github.com/martiiian/nutritions.git
```

## Использование

```bash
deno task dev                          # сегодня
deno task dev -- --date yesterday      # вчера
deno task dev -- --date 05-06          # конкретный день (MM-DD)
```

Скомпилировать в бинарник:

```bash
deno task build
./dist/nutritions --date yesterday
```

### Установка бинарника в систему (Ubuntu)

```bash
deno task build
sudo mv dist/nutritions /usr/local/bin/nutritions
```

После этого бинарник доступен из любого места:

```bash
nutritions --date yesterday
```

## Конфигурация

Обязательные переменные окружения:

| Переменная                | Описание                                 |
| ------------------------- | ---------------------------------------- |
| `NUTRITIONS_PRODUCTS_DIR` | Директория с `.md` файлами продуктов     |
| `NUTRITIONS_TASKS_DIR`    | Директория с дневными логами приёма пищи |

## Формат данных

### Продукт (`.md` в products dir)

Каждый файл — один продукт. Блоки выделяются жирными заголовками:

```markdown
**пищевая ценность** жиры/белки/углеводы/калории (на 100г) размер порции общий
вес

**цена**

- [[2024-01-01]] 150

**состав**

- [[ингредиент]] - 100г

**рецепт**

- шаги приготовления
```

Продукты без блока `пищевая ценность` рассчитывают КБЖУ рекурсивно из
ингредиентов (`состав`).

### Дневной лог

Obsidian-файл в tasks dir (формат `YYYY-MM-DD.md`):

```markdown
- [[название продукта]] - 200г
- [[название продукта]] - 2
```

Если указана единица (г/мл) — значение в граммах. Без единицы — количество
порций (из `portionSize` продукта).

## Вывод

Таблица с КБЖУ по каждому продукту и итоговой строкой за день.
